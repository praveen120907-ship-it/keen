# Assets folder

## assets/photos/
Contains 6 placeholder images (`photo-1.jpg` … `photo-6.jpg`) so the site
works right out of the box. Replace each one with a real photo — **keep the
same file name** and the site will pick it up automatically, in:
- the Relationship Timeline (`index.html`, section `#timeline`)
- the Photo Memories gallery (`index.html`, section `#gallery`)

Recommended: roughly square or portrait photos, under ~1.5MB each, so the
site stays fast on mobile data.

## assets/music/
Add your song here as `our-song.mp3` (exact file name). The floating music
button in the bottom-right corner will play/pause it. If the file is
missing, tapping play just shows "Add your song file to play" — nothing
breaks.

## assets/icons/
Empty on purpose. The whole site intentionally avoids external icon fonts
and images — every icon (♥, ✦, ✧, ♪) is plain text/CSS, so there's nothing
to license or download. Leave this folder as-is, or use it for anything
extra you add later.
